# Градиентные методы оптимизации

Занятие курса «Искусственный интеллект» для 10 класса (практическая работа №2, часть 1О). Ученики пишут градиентный спуск, метод импульса и Adam с нуля, смотрят на простой функции, как скорость обучения и выбор метода меняют путь к минимуму, пишут свой оптимизатор как наследник `torch.optim.Optimizer` и сравнивают готовые оптимизаторы на сверточной сети.

## Теория (презентация)

1. **Градиентный спуск** – шаг против градиента, первый шаг на примере, «овраг» и зигзаги, роль скорости обучения.
2. **Стохастичность** – градиент по мини-пакету, шум мешает и помогает.
3. **Импульс и адаптивность** – шар с инерцией (17 шагов вместо 57), AdaGrad → RMSProp → Adam, планировщики шага.
4. **Пишем оптимизаторы на Python** – группы параметров и состояние оптимизатора, план практики.

## Практическая работа

Сквозной пример – функция $f(w_1, w_2) = w_1^2 + 10\,w_2^2$ со стартом в точке $(-4, 1)$. В конце – обучение `SimpleCNN` из части 4А на FashionMNIST разными оптимизаторами.

1. Градиент и путь градиентного спуска.
2. Множители и траектории.
3. Метод импульса.
4. Adam.
5. Свой оптимизатор `MySGD`.
6. Оптимизаторы и расписание шага на настоящей сети.

Задания повышенной сложности: функция Розенброка, поиск скорости обучения (LR range test), влияние размера пакета.

**Правило работы:** в заданиях О1–О4 оптимизаторы пишутся на тензорах, без `torch.optim`. В О5 – свой класс-наследник `torch.optim.Optimizer`, готовый `torch.optim.SGD` только для сверки. В О6 – готовые `torch.optim` и планировщики.

## Данные

Для заданий О5–О6 нужен FashionMNIST в папке `data`. Скачайте его заранее:

```python
from torchvision import datasets
datasets.FashionMNIST('data', train=True, download=True)
datasets.FashionMNIST('data', train=False, download=True)
```

Если набор не найден, ноутбук подставляет случайные картинки `FakeData`, чтобы код выполнялся, но точность в этом случае ничего не значит.
